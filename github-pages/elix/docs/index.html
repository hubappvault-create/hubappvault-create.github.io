Install

  1. Run the installer (.msi) on the server as an administrator. ELIX installs to C:\Program Files\Elix.
  2. Open ELIX Remote Access Console from the desktop or Start menu.
  3. The console sets up its background services on first start. If the red "Configuration service is offline" bar appears, wait a few seconds and click Retry.

Uninstalling keeps your configuration and license, so a reinstall picks up where you left off.

Users and sessions

The Users page lists the server's Windows accounts with their session state (Active, Disconnected, Not Connected). Use the … menu on a row to disconnect, shadow, log off or change that user's settings. Generate Client creates a connection file for the desktop client.

App assigning

On App Assigning, publish an application or folder, then add the users or groups who may use it. A user with assigned apps signs in to the ELIX panel showing only those apps, instead of the full Windows desktop. Remove all of a user's apps to give them the normal desktop again.

Web access

Users can work from a browser with no client installed.

  1. Open Web in the console and choose a port: Auto Select (5000–5300) or Manual Select (for example 443), then Save.
  2. Click Start Web Service. ELIX opens that port in Windows Firewall.
  3. If your hosting provider has its own firewall, open the same port there too.
  4. Users open https://your-domain (or https://your-domain:port when not on 443). Always type https://.

Connected Web Users shows who is signed in through the browser, and can disconnect a user (their Windows session stays signed in).

HTTPS certificate

Web → Free SSL Certificate gets a free certificate from Let's Encrypt.

Before you start

  • Your domain's DNS points to this server's public IP address.
  • Ports 80 and 443 are open (Windows Firewall and any provider firewall), and nothing else uses port 80 (for example IIS).
  • Run it on the gateway or a standalone server, not an application server.

The web service briefly moves to port 80 while Let's Encrypt checks the domain, then switches to HTTPS on port 443. Certificates last 90 days and renew automatically when fewer than 25 days are left. Port 80 must still be reachable then. Back up C:\Program Files\Elix\current\certs regularly.

Updates

Settings → Updates checks for a new version and installs it. Users connected during an update are disconnected briefly while the services restart.

Troubleshooting

The website times out

The port is blocked. Check the console's Web page shows the service running, then click Restart Web Service — it re-creates the Windows Firewall rule. If it still times out, open the port in your hosting provider's firewall.

"This page isn't working" / empty response

The address was opened with http://. With a certificate installed the portal only answers https://.

Certificate warning in the browser

Open the portal by its domain name, not the server's IP address — the certificate is for the domain.

"Incorrect username or password" on a domain server

On a domain controller or domain member, users sign in with their domain account. Turn on the domain field (Web → Server Configuration) so users can enter their domain on the sign-in page.
