ELIX Remote Access

Turn a Windows server into a remote workplace. Users connect from their own PC or any web browser, see only the apps you give them, and print to their own printers. You manage it all from one console.

What it does

Desktop client

Users sign in with a client file you generate: full desktop, seamless windows or individual remote apps.

Browser access

Work from any web browser with nothing to install, secured with a free HTTPS certificate that renews itself.

Published apps

Give each user or group only the applications they need. They see a simple app panel instead of the Windows desktop.

Printing

Print from the server to the user's own printer, or to PDF, through the built-in Remote Printer.

Users and sessions

See who's connected, disconnect, shadow or message users, and lock down each user's desktop, drives, apps and working hours.

Security

IP allow and block lists, brute-force login protection, access log, and optional two-factor authentication, geo blocking and MAC filtering.

One console

Live server resources, active sessions, license and quick access to Windows tools, in light or dark mode.

Backup and updates

Scheduled backups to a local drive or Google Drive, export and restore of the whole configuration, and in-app updates.

Runs on

Windows Server 2016, 2019, 2022 and 2025, and Windows 10 / 11. See Getting started for full requirements.
