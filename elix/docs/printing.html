Printing

ELIX installs a virtual printer on the server called Remote Printer. When a user prints to it, the document comes out on their own computer.

Install the Remote Printer

  1. Open the Dashboard and find the Printer card.
  2. Click Install and confirm.
  3. When it's done, the card shows the printer as available.

Use View to see the server's printers and Remove to uninstall the Remote Printer.

Printing from a session

  1. In the app, choose Print (or press Ctrl + P).
  2. Pick Remote Printer and click Print.
  3. On the user's PC the document appears as set by the client file's Universal Printer Option: a PDF preview, a saved PDF, or straight to their default printer.
Printing to the Remote Printer works with the Seamless and Remote App client types, not the Remote Desktop client type.

Printing from a browser session

Turn on Printer Download in Web → Session Configuration. When a user prints to the Remote Printer, their browser downloads the document as a PDF.

Special paper (half page, cheques)

Custom paper sizes must exist on the server as well as on the user's PC. If half-page or cheque prints come out wrong for everyone, check the paper size in the printer's preferences and in the application's Print Setup. See Troubleshooting → Printing.
