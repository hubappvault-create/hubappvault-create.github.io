Settings

Everything that controls how the server behaves. Pick a section on the left of the Settings page; only the right-hand side scrolls.

Account

Change the console's Master Password and set a Quick-Unlock PIN. See The console → Your account.

Session Management

Connection Settings

  • Reconnection: end disconnected sessions after a set time, limit how long a session or an idle session may last, or end all of a user's sessions when they disconnect.
  • User connection: when the same user signs in twice, end the first session, block the second, or allow several sessions.
  • Only generated client will allow the login: users can only sign in with an ELIX client file.
  • Turn on MAC address filtering: only approved computers can connect (managed under MAC Address Filter).

Permission Control

Set folder permissions for users and groups: allow or deny read, write and execute, and choose whether permissions are inherited from the parent folder.

License

Activate, check or renew your license and see which features it includes.

Windows Tools

Shortcuts to Windows' own tools: Services, Computer Management, Task Scheduler, Event Viewer, Control Panel, Local Users and Groups, Active Directory Users and Computers, Group Policy Editor and Registry Editor.

Firewall Configuration

Block or allow IP addresses. Filter the list by All, Blocked or Allowed.

  • Blocked addresses can't connect or sign in.
  • With Allowed addresses in use, only those can connect; everyone else is refused.

Login Protection

Stops password-guessing attacks on Remote Desktop: after too many failed sign-ins, the address is blocked. See the Blocked IPs and Recent Failed Logons, and unblock an address if needed.

Access Log

Recent sign-ins that were refused, and why. You can choose to notify users when they are denied.

Backup

  • Backup Sources: add the folders and files to back up.
  • Backup Destination: a local or network drive, or Google Drive. Connecting Google Drive opens your browser to sign in and allow access. ELIX can only see the files it creates there.
  • Schedule Backup: turn on automatic backups and choose when.
  • Backup Now: run a backup immediately.

Export & Restore

Export the console's configuration to a file, and restore it on this or another server (for example after reinstalling Windows).

Updates

Check for a new ELIX version, read what's new, and install it. Users are briefly disconnected while the services restart.

Two-Factor Authentication (license add-on)

Users confirm their identity with a second step when signing in. Set it up under Server Setting, manage enrolled users under User Management, and exempt trusted users with the White List.

Geo Block (license add-on)

Refuse connections from chosen countries or regions. Choose the regions and which ports to protect.

MAC Address Filter (license add-on)

Shown when MAC address filtering is on in Session Management. Add the MAC addresses of the computers that may connect.

Restart Services

Restart the ELIX services on the server. Use it when something stops responding. Users may be disconnected briefly.
