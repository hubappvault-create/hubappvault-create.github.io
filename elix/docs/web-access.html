Web access

Users can work from a web browser with nothing installed. Set it up on the console's Web page.

Start the web service

  1. Open Web.
  2. Choose a port: Auto Select (picks a free port between 5000 and 5300) or Manual Select and type one (for example 443), then click Save.
  3. Click Start Web Service. ELIX opens the port in Windows Firewall.
  4. If your hosting provider has its own firewall, open the same port there too.

Stop disconnects everyone and keeps the service off after a reboot until you start it again. Restart briefly disconnects users and also repairs the port's firewall rule.

The pill next to the port shows whether the portal is secured: HTTPS with the domain and days left, or Not secured (http). Click it to manage the certificate.

Connected Web Users

Shows who is signed in through the browser: user, IP address (local network or internet), browser or device, and how long they've been connected. It also shows whether they are active or idle.

The disconnect button closes that user's browser session. Their Windows session stays signed in, so their programs keep running and they can sign back in.

Free HTTPS certificate

Web → Free SSL Certificate gets a free certificate from Let's Encrypt, so users see the padlock and no warnings.

Before you start

  • A domain name (for example remote.yourcompany.com) points to the server's public IP address.
  • Ports 80 and 443 are open in Windows Firewall and in any provider firewall, and nothing else uses port 80 (for example IIS).
  • Run it on the gateway or a standalone server, not an application server.

Generate

  1. Enter the Administrator Email and the domain name(s).
  2. Choose the Key Algorithm (RSA is the most compatible).
  3. Click Generate a free valid HTTPS certificate. The web service briefly moves to port 80 while Let's Encrypt checks the domain, then switches to HTTPS on port 443.

Certificates last 90 days and renew automatically when fewer than 25 days are left (port 80 must still be reachable then). Back up C:\Program Files\Elix\current\certs.

Session Configuration

How browser sessions behave: clipboard, glyph cache, Printer Download, async input, session sharing and the maximum number of guests. Also the default folder, appearance (wallpaper, font smoothing, window drag, menu animations, Aero, mouse motion, visual theme), colour depth and a program to start on sign-in.

Server Configuration

Connection and performance: the option panel users see (clipboard, file manager), server appearance, image quality and format, file upload and download limits, and advanced options (image compression, bitmap cache, ignore certificate errors, async channels and updates, off-screen cache).

Show Domain Field adds a Domain box to the sign-in page. Turn it on when users sign in with domain accounts.

Signing in from a browser

  1. Open the address you were given, starting with https://, for example https://remote.yourcompany.com, or https://remote.yourcompany.com:5000 when not on port 443.
  2. Enter your user name and password (and domain, if shown) and click Connect.
  3. Users with assigned apps get the ELIX panel; everyone else gets the full desktop.

Option panel

  • Clipboard: copy and paste between your PC and the session. The browser may ask once for permission to read the clipboard; click Allow.
  • File Manager: upload files (right-click an empty area) and download files (right-click a file).
  • Reconnect and Disconnect.
