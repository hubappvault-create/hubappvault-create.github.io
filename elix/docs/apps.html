App assigning

Publish applications and folders, then choose which users or groups get them. A user with assigned apps sees only those apps in the ELIX panel, never the full desktop.

Publish an application

  1. Open App Assigning.
  2. Click Application (bottom of the Published column).
  3. Click the folder button next to the path and choose the program's .exe.
  4. Enter a Display Name users will see (for example "Invoice System").
  5. Optional: add command-line arguments to start the app in a particular mode.
  6. Click Save. The app appears under Published.

Use Folder the same way to publish a folder. Test starts the app on the server so you can check it works. The pencil and bin buttons edit or remove the selected item.

Assign it

  1. Click the published app to select it.
  2. Click Add User. The Windows "Select Users or Groups" window opens.
  3. Type a name, or use Advanced → Find Now to list users and groups. Hold Ctrl to pick several.
  4. Click OK. They appear under Selected.

Click a user to see all the apps they have under Assigned Applications. Assigning to a group gives the app to everyone in it.

When changes take effect

Users who are signed in must sign out and sign back in to see new or removed apps.

Remove all of a user's apps to give them the normal Windows desktop again.
