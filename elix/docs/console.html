The console

The ELIX Remote Access Console is where you manage the server. Pages open from the bar on the left.

Left bar

HomeThe Dashboard: server status at a glance.
UsersWindows users, their sessions, and client files. See Users and clients.
App AssigningPublish apps and assign them. See App assigning.
SettingsEverything else. See Settings.
WebBrowser access. See Web access.

The footer has links to these docs and to support, and a light / dark theme switch.

Dashboard

Status strip

Shows how many users are active and whether the ELIX services and the web service are running.

System resources

Live CPU, memory and disk use of the server.

Active sessions

Everyone signed in right now, with their computer, IP address and how long they have been connected. Use the buttons on a row to open the user on the Users page or to Disconnect them. With many users the list scrolls inside the card.

Printer

Install, view or remove the Remote Printer. See Printing.

License

License type and days left. View details opens Settings → License.

Quick access and PC information

Shortcuts for common jobs (such as Restart Services and the firewall), and the server's details: IP address, RDP port, computer name and Windows version.

Changing the RDP port

You can change the Remote Desktop port from PC information. Windows only switches to the new port after the server restarts. After that, connect using the new port and update any client files that use the old one.

Your account

The account icon at the top right and Settings → Account manage how you open the console:

  • Master Password: the password that protects the console. After changing it, use the new password next time.
  • Quick-Unlock PIN: a shorter PIN for opening the console. Set the master password first. If you forget the PIN, sign in with the password and set a new PIN.
