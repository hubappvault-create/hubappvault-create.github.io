Getting started

What the server needs, how to install ELIX, and what happens on first start.

Requirements (server)

Operating systemWindows Server 2016, 2019, 2022 or 2025, or Windows 10 / 11
Memory8 GB RAM or more recommended (more for many users)
Disk20 GB or more free on drive C:
CPUEnough for the number of users you expect
PermissionsA local administrator account to install and run the console
Printing (optional)Printer drivers, if you use printer redirection

Install

  1. Get the latest ELIX installer (.msi) from your supplier.
  2. Double-click it on the server and click Yes when Windows asks for permission.
  3. The installer adds everything ELIX needs (the .NET runtimes, WebView2 and the Visual C++ runtime) and installs to C:\Program Files\Elix.
  4. When it finishes, open ELIX Remote Access Console from the desktop or the Start menu.
On first start the console sets up its background services and turns on Remote Desktop. If a red Configuration service is offline bar appears, wait a few seconds and click Retry.

Your license

Open Settings → License to activate or check your license. The Dashboard's License card shows the type and the days left.

TrialAll features for a limited number of days.
RentalRenewed every year. Includes updates, fixes and support. Add-on features can be bought separately.
PerpetualOne-time purchase, no expiry. Add-on features can be bought separately. Support needs an active support license.

Updating and uninstalling

Install updates from Settings → Updates. Uninstalling ELIX keeps your configuration and license, so a reinstall picks up where you left off.
