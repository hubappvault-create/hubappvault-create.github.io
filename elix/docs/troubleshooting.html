Troubleshooting

Common problems and fixes. If you're still stuck, contact support.

The console or services aren't working

  • Windows update pending: let it finish, then restart the server.
  • Antivirus blocking ELIX: allow C:\Program Files\Elix in your antivirus, or pause it briefly to test.
  • "Configuration service is offline": click Retry. If it stays, use Settings → Restart Services, or restart the server.

License won't activate (computer ID changed)

Being connected to several networks at once (Wi-Fi and Ethernet, or several Wi-Fi networks) can change the computer's ID. Disconnect all but one stable connection (preferably Ethernet), restart, and activate again. If it still fails, contact support with your license details.

A user sees the desktop instead of their apps (or no panel)

  1. In the client's login window, click Clear Save Data, confirm, close the login window and open it again.
  2. Still wrong: on the server, remove all of the user's apps, have them sign out, assign the apps again, and sign in again.

New or removed apps only show after the user signs out and back in.

Printing problems

Remote Printer missing or failingDashboard → Printer → Remove. Restart the Print Spooler service (Windows Tools → Services). Then Install the printer again and test.
User signed in twiceClose the other sessions and sign in again.
Wrong client typePrinting needs the Seamless or Remote App client type. Generate a new client file with one of those.
ELIX services stoppedSettings → Restart Services.
Half-page or cheque prints come out wrong for everyoneUsually Windows settings, not ELIX: often after a power cut or Windows update. Check the paper size in the printer's Printing preferences and the app's Print Setup, restart the printer, and sign out and back in.

Several users can't sign in at once

Check the ELIX services are running (Settings → Restart Services). Also check Session Management → User connection isn't set to allow only one session.

Web access

The website times out

The port is blocked. On the console's Web page check the service is running, then click Restart Web Service: it re-creates the Windows Firewall rule. If it still times out, open the port in your hosting provider's firewall.

"This page isn't working" / empty response

The address was opened with http://. With a certificate installed the portal only answers on https://.

Certificate warning in the browser

Open the portal by its domain name, not the server's IP address. The certificate is for the domain.

"Incorrect username or password" with the right password

On a domain server, users sign in with their domain account. Turn on Show Domain Field (Web → Server Configuration) and enter the domain on the sign-in page.

The browser keeps asking about the clipboard

Click Allow once. If you clicked Block, re-allow it from the padlock icon next to the address.
