Client app and login

How a user installs the ELIX client on their own computer and signs in with their client file.

1. Get the client installer

The client installer (ClientSetup….exe) is placed on the server's public desktop when ELIX is installed. Send it to your users together with their .rhost file (see Generate a client file).

2. Install it on the user's PC

  1. Run ClientSetup….exe and allow it to make changes.
  2. Wait for "Please wait while Windows configures ClientSetup" to finish.

3. Sign in

  1. Double-click the user's .rhost file (for example Test1.rhost).
  2. Enter the password (and the user name if the file doesn't include one).
  3. Click Connect.
User has assigned appsThe ELIX panel opens with only those apps. Double-click an app to start it.
No assigned appsThe full Windows desktop opens.

Domain users

On a domain server, enter the Domain Name when you generate the client file. Without it, sign-in can fail even with the right password.

Signing in from a browser instead

Users can also work from a web browser without installing anything. See Web access → Signing in from a browser.
