Users and clients

Every person who connects needs a Windows user on the server. Then you give them a client file (or the web address) to sign in with.

Create a user

  1. Open Users and click Create User.
  2. Enter the user name and password.
  3. Keep Add to Remote Desktop Users ticked. Without it the user can't connect.
  4. Click Create.
You can also use Windows' own tools: Settings → Windows Tools → Local Users and Groups (or Active Directory Users and Computers on a domain). Add the user to the Remote Desktop Users group.

The Users page

Lists the server's users with their session. Filter with Active, Disconnected, Not Connected or All, or search by name. Only the table scrolls; the filters and buttons stay in place.

The … button on a row opens:

DisconnectEnds the connection. The user's programs keep running and they can reconnect.
ShadowView or control the user's session (to help them).
Send messagePop up a message on the user's screen.
User SettingRestrictions for this user (below).
Log OffSigns the user out and closes their programs. Unsaved work is lost.
Delete accountRemoves the Windows user.

User Setting

Desktop SecurityHide or block parts of Windows: recycle bin, Task Manager, recent files, folder options, Control Panel, CMD, printer deletion and system tools.
Disk ControlChoose which drives the user can see.
Application ControlChoose which programs the user may run.
Working HoursAllow sign-in only at set times.

Changes apply the next time the user signs in.

Generate a client file

A client file (.rhost) holds the server's address and settings. The user opens it with the ELIX client app to sign in. Click Generate Client on the Users page; the wizard has three steps.

1. Setup Security

Choose the User Security Level and extras such as encryption, a show/hide password button, and hiding the server's IP address and port from the user.

2. Setup Local Resources

Choose what from the user's PC is available in the session: disks, clipboard, printers, sound, COM ports, USB devices, smart cards, a shared folder, and how the keyboard behaves. Universal Printer Option sets what happens when they print: Preview with local PDF Reader, Save as PDF or Direct Print.

3. Fill General Details

  • Server Address and Port Number (Auto Fill can fill these in).
  • Domain Name: required when users sign in with a domain account.
  • Login: one user, several users, or none (the user types their name).
  • Client Type: Remote Desktop Client (full desktop), Seamless Client or Remote App Client (apps appear like local programs).

Click Generate and choose where to save. With several users, ELIX saves one file per user in a folder. Send each user their file.

Use the Seamless or Remote App client type for users who need to print to the Remote Printer.
